# 점수 산정 방법 (Scoring)

이 앱은 **오로지 사주 특성만으로** 궁합을 점수화합니다(인물에 대한 사전 정보는 쓰지 않음). 모든 로직은 `index.html`의 인라인 스크립트에 있으며, 핵심 계산 함수는 전통 명리학 이론과 대조 검증되었습니다.

> 면책: 명리학은 과학이 아니며, '덕질 궁합'과 아래 가중치는 이 앱의 **해석적 설계**입니다. 오락용입니다.

## 0. 기둥 계산

| 기둥 | 방법 |
|---|---|
| 일주(日柱) | 율리우스일수(JDN) → 60갑자. `stem=(JDN+9)%10`, `branch=(JDN+1)%12`. **JDN·날짜차 2방식 교차검증.** |
| 시주(時柱) | 오호둔(五鼠遁). 분 단위 입력 + **진태양시 보정**(기본 적용, 토글로 끌 수 있음): 자시=23:30(전날)~01:30 기준 2시간 블록. 보정을 끄면 표준시 23:00~00:59 기준. |
| 년주(年柱) | `(연-4)%10 / %12`, **입춘(≈2/4) 경계**로 연 보정. |
| 월주(月柱) | 절기 근사 경계로 월지 결정 + 오호둔으로 월간 결정. |

절기·입춘 경계는 일(日) 단위 근사라 경계일(±1~2일)은 어긋날 수 있습니다.

## 0-1. 오행 분포 (참고용 · 궁합 점수에는 미반영)

년·월·일·(시)주의 천간 + 지지(支藏干 정기 기준) 오행을 모두 세어 비율을 낸 단순 글자수 집계입니다. 시각 입력 시 8자, 미상 시 6자 기준.

```
pct(오행) = 해당 오행 글자 수 / 전체 글자 수 × 100
```

지장간의 중기·여기까지 가중하는 정밀 방식이 아니라 정기(대표 천간) 1개만 세는 단순화입니다. 궁합 순위 점수 계산에는 사용하지 않으며, 사용자에게 자신의 오행 편중을 보여주는 참고 지표입니다.

## 1. 십신 10신 (일간 기준)

상대 천간이 일간과 맺는 오행 관계(생·극·동)와 음양(정/편)으로 10신을 정하고, '덕질 = 내가 애정을 쏟는 관계'라는 관점의 가중치를 부여합니다.

| 계열 | 신(神) | 가중치 | 의미(덕질 관점) |
|---|---|---|---|
| 식상 | 상관 / 식신 | 40 / 38 | 내 기운이 흘러가는 대상 — 애정을 쏟는 최애 |
| 인성 | 정인 / 편인 | 33 / 30 | 나를 북돋는 대상 — 힐링·충전 |
| 재성 | 정재 / 편재 | 24 / 22 | 내가 끌어당기는 대상 — 설레는 매력 |
| 비겁 | 겁재 / 비견 | 15 / 13 | 같은 기운 — 친구 같은 편안함 |
| 관성 | 정관 / 편관 | 8 / 6 | 나를 조이는 대상 — 긴장·경외 |

정(正)=음양 다름, 편(偏)=음양 같음. 5계열을 10신으로 나눠 **동점을 줄이고** 음양의 결까지 반영합니다.

## 2. 부가 레이어 (합산)

| 레이어 | 규칙 | 가중치 |
|---|---|---|
| 천간합(天干合) | 일간끼리 甲己·乙庚·丙辛·丁壬·戊癸 합 | +6 |
| 지장간(支藏干) | 상대 일지 정기의 십신 (중심 20 기준) | ×0.15 |
| 일지(日支) 궁합 | 육합 +14 · 삼합 +11 · 방합 +6 · 비화 +4 · 평 0 · 해 −6 · 충 −14 | ×1.0 |
| 년지(띠) 궁합 | 위 지지 관계 점수 | ×0.4 |
| 월지 궁합 | 위 지지 관계 점수 | ×0.3 |
| 시지(時支) 궁합 | 시각 입력 시, 사용자 시지 ↔ 상대 일지 | ×0.6 |

지지 관계는 육합/삼합/방합/충/해/비화 테이블로 판정합니다(전통 값과 대조 검증됨).

## 2-1. 격국(格局) 궁합

나와 상대 각각의 '우세 십신 계열'(=간이 격국)을 추정하고, 두 계열의 관계를 오행 상생상극에 유비해 가점합니다. 정통 격국론(용신·격 성립 조건 등)이 아니라, 이 앱이 이미 쓰는 십신/오행 유비를 한 단계 더 확장한 해석입니다.

- **우세 계열 추정** (`dominantFamily`): 해당 인물의 년·월·일·(시)주에서 일간 자신을 제외한 나머지 글자(천간+지장간)를 십신 계열(식상·인성·재성·비겁·관성)로 분류해 가장 많이 나온 계열을 그 사람의 격으로 봅니다. 아이돌은 년·월·일주(공개된 생년월일 기준)로, 사용자는 여기에 시주까지(입력 시) 더해 계산합니다.
- **계열 간 관계**: 비겁→식상→재성→관성→인성→비겁 순으로 순환하는 구조가 오행 상생 순서(木→火→土→金→水)와 그대로 대응한다는 점을 이용해, 기존 `relation()` 함수를 그대로 재사용해 판정합니다.
- **가중치** (동일 서열: 식상>인성>재성>비겁>관성):

| 관계(내 격 기준) | 가중치 |
|---|---|
| 내가 상대 격을 생(식상 관계) | +9 |
| 상대 격이 나를 생(인성 관계) | +7 |
| 내가 상대 격을 극(재성 관계) | +5 |
| 같은 격(비겁 관계) | +3 |
| 상대 격이 나를 극(관성 관계) | +1 |

십신 10신(±13~40)이나 지지 관계(±14)보다 작은 폭(+1~+9, 전부 양수)으로 설계해 **보조 신호**로만 작동하도록 했습니다.

## 3. 신강/신약 개인화 (억부)

사용자 사주(년·월·(일·시)주)에서 일간을 **돕는 세력(비겁·인성)** 과 **빼는 세력(식상·재성·관성)** 의 비율로 신강/신약을 판정합니다. 일간 자신은 기준점이라 세력 계산에서 제외하고, 월지는 가중(월령)합니다.

- `need = 0.5 − (도움 비율)` → `need>0` 신약, `need<0` 신강 (범위 대략 ±0.4)
- 각 상대의 십신 가중치를 계열별로 보정: `조정치 = 방향 × need × 10`
  - 신약(need>0): **인성·비겁 가점**, 식상·재성·관성 감점
  - 신강(need<0): 반대

→ 같은 상대라도 **사용자마다 점수·순위가 달라집니다.**

## 3-1. 신청자 성별 (선택 · '이성 인연' 반영)

성별을 선택하면 명리에서 '이성 인연'에 해당하는 십신 계열을 소폭 반영합니다.

- **남성** → **재성(정재·편재)**, **여성** → **관성(정관·편관)** 계열에 `+8` 가점(신강/신약 가중보다 작게).
- 해당 관계의 역할 라벨을 "이성적 매력형"으로, 관성의 경우 이유 문구를 이성적 끌림 맥락으로 리프레이즈합니다.
- **미선택 시 성별 중립**(기존 계산과 동일). 공유 이미지·결과 라벨에 성별은 노출하지 않습니다.

이는 정통 명리의 재성=이성(남)·관성=이성(여) 통변을 오락적으로 가볍게 반영한 것으로, 앱의 핵심 '덕질(식상·인성 상위)' 설계를 뒤집지 않는 범위로 제한했습니다.

## 4. 정규화

한 사용자 기준으로 전체 풀의 원점수 `raw`를 구한 뒤, **최소~최대로 선형 정규화**하여 0~100(%)로 만들고 **소수 둘째 자리**까지 표기합니다. 필터(카테고리/소속사/성별)와 무관하게 값이 고정되도록 전체 풀 기준으로 계산합니다.

```
pct = round( (raw − min) / (max − min) × 100 , 2)
```

## 5. 나의 사주 총평 (서사형 해석 · 참고용)

일간(10종) + 신강신약(3종) + 격국 우세 계열(5종)을 조합해 문단 3개짜리 개인 총평을 보여줍니다(`renderNarrative`). 순위 점수 계산에는 관여하지 않는 표시 전용 기능입니다. 문장은 전통 십간론·억부론·격국론에서 통상적으로 쓰이는 뜻을 바탕으로 직접 작성했으며, 특정 철학관·서비스의 해설을 옮긴 것이 아닙니다.

## 검증

`index.html`의 함수들은 다음 textbook 값과 대조해 일치를 확인했습니다: 오호둔 시주(甲일 子시=甲子 등), 년/월주, 육합·삼합·충·해 테이블, 십신(정재·편관·상관 등), 천간합, 지장간 정기. 일주 계산은 별도로 JDN·날짜차 2방식 + 앵커 6~7건으로 교차검증합니다.
